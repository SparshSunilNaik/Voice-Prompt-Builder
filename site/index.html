Why it's different

A prompt engineer that interviews you, then writes the prompt.

Just speak

No blank text box. Explain the problem the way you'd tell a colleague, then fix the transcript if you need to.

Questions, out loud

Each multiple-choice question is read aloud and the mic opens by itself. Say "option two" or answer in your own words. Every question builds on your last answer.

The right technique

Zero-shot, one-shot, few-shot, chain-of-thought or decompose-and-verify, plus role, structure and self-critique. Chosen for your task, not one template for everything.

It learns from your feedback

Hit Regenerate and it asks what was wrong: too long, too vague, wrong tone, wrong technique. It fixes the prompt and remembers the lesson for every future prompt.

In our tests, one round of "too long, wrong tone" cut a prompt from 331 to 270 words.

Never hits send

It places the prompt in ChatGPT, Claude or Gemini, protects any draft already there, and leaves sending to you.

How it works

From a rough idea to a precise prompt.

Speak

Open the side panel on any supported chat site and describe what you need.

Clarify

Answer a few adaptive questions by voice, a tap or typing. Stop early whenever you like.

Build

Review the prompt and the techniques it chose. Edit it, or regenerate with feedback.

Insert

Approve, and it lands in the chat box. You read it and press send yourself.

Get the beta

Free, open source, and runs on your computer.

The beta runs a small local server next to Chrome, so your speech and API keys never pass through our servers. Setup is four steps.

You'll need

  • Chrome 116+ on Windows, macOS or Linux
  • Python 3.11+, Node.js 22 or 24 and FFmpeg
  • A Gnani API key for speech-to-text
  • An OpenRouter API key for the prompt model (you pay only your own usage)
Download beta (.zip) Full setup guide

Set up in four steps

  1. Unzip the download and copy .env.example to .env. Add your Gnani and OpenRouter keys.
  2. Start it. Windows: run .\start.ps1 in PowerShell. macOS/Linux: ./start.sh. It installs everything and prints a local access token.
  3. Load the extension. Open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the extension/dist folder.
  4. Connect. Open ChatGPT, Claude or Gemini, click the extension icon, paste the token into Backend connection, and start speaking.

Is it free?

Yes. The extension is free and open source. During the beta you use your own Gnani and OpenRouter keys, so you pay only for your own usage with those providers.

Which AI chat sites does it work with?

ChatGPT, Claude and Gemini today. You can also copy the finished prompt and use it anywhere.

Why do I have to run something on my computer?

So your voice recordings and API keys never pass through a third-party server. A one-click Chrome Web Store version is planned. Request beta access and we'll let you know when it's ready.

Can I just type instead of speaking?

Yes. Text mode gives you the same adaptive questions with buttons, and you can switch between voice and text at any point.
